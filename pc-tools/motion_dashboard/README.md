# 小车运动数据交互报告

双击桌面 **查看小车运动数据.cmd**。脚本只读车端最近一次已经结束、发送过行驶任务且记录器完成保存的运行。在浏览器显示报告，不启动小车、不修改参数、不复位急停。

页面包含速度、舵机 PWM、车身角速度、电机 PWM、路径对比、路径偏差、基础转向角与闭环修正，以及原始三轴陀螺仪角速度和 IMU 航向角。路径蓝箭头取自定位 yaw，等长表示车头方向；约每秒采一点，长记录自动降低密度，悬停采样点可查看时间、位置和角度。拖动框选、鼠标滚轮或底部滑块缩放时间范围；所有时间图联动。双击或顶部复位按钮恢复。悬停读数，单击图例隐藏曲线，图表相机按钮导出 PNG，顶部按钮分别导出闭环数据和 IMU 数据 CSV。

首页：`D:/RacecarWork/reports/motion-dashboard/index.html`。每次还生成按运行编号命名的独立 HTML，以及 data 目录下的原始精简数据和绘图数据 JSON。图表库嵌入 HTML，离线可打开。下拉框包含最近 20 份已下载缓存；首次只包含本次获取的记录，不会批量下载车上所有历史日志。重新双击桌面入口才会读取车端新数据。

正在运行或仅预检查的记录会被跳过，并在页面显示提示。连接失败且已有缓存时显示明确警告并打开缓存；没有缓存则保留错误信息。使用共享地址配置和主机密钥进行只读地址发现，不更改主线程的连接配置。车端流式读取 raw.jsonl，仅返回提取的 /IMU_data 字段；若闭环 CSV 尚未生成，同时提取闭环诊断。不会把整份原始日志传到电脑。旧缓存缺少 IMU 时明确提示，使用 --run 重新读取该轮记录可补充。

## 数据口径

- 速度是定位里程计反馈，最高值是有效激活样本的采样峰值。不是独立测速仪真值；不把无效反馈填成零。
- 均速对连续、有效、激活的反馈做梯形时间加权；不跨大于容许间隔的数据缺口积分。页面显示有效覆盖时长。
- 时间零点是首个闭环激活诊断样本，任务时长来自 session.json 的 elapsed_s。
- 舵机、电机 PWM 是软件成功写出的指令；基础角、修正角不是实测舵角。
- 路径用共同参考起点平移旋转，不进行事后拟合。误差是到最近参考线段的几何距离，左正右负；八字交叉处不能替代控制器顺序进度。
- 顶部最大偏差仅统计首末激活诊断样本之间的有效定位点。图中以灰色保留其他时段的定位，避免将停车后的定位变化混入行驶指标。
- 无效定位、记录缺口在图中断开；没记录的数据不补造。
- 路径箭头将定位 yaw 减去参考起点 yaw，与路径坐标变换保持一致；不是目标点方向或直接测得的轮胎方向。
- 所有橙色和灰色定位点，以及蓝色箭头采样点，悬停均显示车头角、IMU 航向角、轨迹移动方向角。前两种数据按各自源时间戳匹配（IMU 最大时间差 100 ms，悬停显示实际差值）。移动方向由前 0.2 秒位移计算，起点在有效定位点之间插值；不足 2 cm 或跨记录缺口不显示角度。车头角与移动方向以图中 +X 为 0°、逆时针为正；IMU 保持原始参考系。目标参考路径没有测量时间，不附加实测角度。
- IMU 使用消息源时间戳，与其余曲线共用时间零点；陀螺仪单位 rad/s，航向角单位度。航向角由归一化后的姿态四元数转换，使用传感器参考系，±180°处折返；没有有效姿态时留空，不用目标路径推算。陀螺仪曲线为日志中已记录样本，不宣称覆盖设备全部原始采样。

## 命令

```powershell
& D:\RacecarTools\envs\yolov5\python.exe D:\RacecarWork\tools\motion_dashboard\run_dashboard.py
# 仅浏览缓存
& D:\RacecarTools\envs\yolov5\python.exe D:\RacecarWork\tools\motion_dashboard\run_dashboard.py --offline
# 指定车端已有记录
& D:\RacecarTools\envs\yolov5\python.exe D:\RacecarWork\tools\motion_dashboard\run_dashboard.py --run s-curve-20260928-155017-678257
```

实现仅使用 Python 标准库和随工具保存的 Plotly.js 2.35.2（MIT，来源 https://cdn.plot.ly/plotly-2.35.2.min.js）。不需要安装 Plotly Python 包、启动网页服务或持续连接互联网。

10 项统计、坐标方向、IMU 有效性、时间匹配、轨迹位移方向及采集测试通过；真实数据页面在 Edge 无头浏览器中验证 9 张图、蓝色方向箭头、定位点三种角度悬停、框选缩放、时间轴联动、复位、历史切换及两种 CSV 下载。加入 IMU 后一次真实读取和生成约 3.4 秒，不包含浏览器首次启动时间；断线发现和大日志解析可能更久。
