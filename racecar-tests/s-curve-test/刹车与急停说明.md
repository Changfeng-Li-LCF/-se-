# 刹车与急停

2026-09-27。用户确认：PWM 回到 1500 时仍会滑行；制动采用反向 PWM，但反向 PWM 值与持续时间尚未实测。

因此当前分为两部分：

- 软件急停：锁住驱动输出，键盘和导航不能覆盖；可使用。
- 反向脉冲制动：逻辑已加入，参数未测，默认禁用；不能宣称实车已经有可靠的主动刹车。

## 制动过程

明确启用并填入经过验证的参数后，最后一条成功发送的电机指令为前进时，急停会输出一次反向 PWM 脉冲，再回到 1500 并保持锁定。制动期间保持触发时的舵机 PWM。重复急停不延长脉冲，不再次触发反转；静止启动、已锁定状态和驱动重启只保持中立。

制动启用后，前进中的零油门指令或指令超时也会触发这套制动并锁定。继续行驶前需要明确解除。未启用反向制动时，原来的零油门和超时行为仍为中立停车；显式急停仍会锁定。

正常行驶继续受 `motor_min_pwm=1500`、`motor_max_pwm=1600` 限制。只有专门的制动状态允许输出已配置的反向 PWM，不会放开普通倒车指令。

当前统一配置是：

```yaml
reverse_brake_enabled: false
brake_pwm: 1500.0
brake_duration_s: 0.0
```

这些是禁用占位值，不是建议的制动参数。以后只修改统一的 `/home/bianbu/racecar/src/racecar/config/driver_calibration.yaml`，同步安装配置并重启驱动。代码只接受已启用时低于中立值、且在协议范围内的 PWM，以及大于 0、不超过 0.5 秒的脉冲。这个时长范围是软件保护边界，不是已测得的刹车效果。

## MobaXterm 命令

驱动运行时，锁存急停：

```bash
bash ~/racecar-tests/s-curve-test/emergency_stop.sh
```

目前执行它只会保持 1500 并锁定，不会反转，车辆仍可能滑行。对应服务是 `/racecar_driver/emergency_stop`，类型 `std_srvs/srv/Trigger`。

解除急停：

```bash
bash ~/racecar-tests/s-curve-test/reset_emergency_stop.sh
```

必须先停止键盘/导航指令流，并至少经过一个 `command_timeout_s` 间隔（目前 0.5 秒）。制动脉冲未结束、指令仍持续进入、中立写入失败或锁定文件无法清除时，解除会被拒绝。解除只允许接收之后的新指令，不主动发车。

程序可向 `/emergency_stop` 发布 `std_msgs/msg/Bool` 的 `true` 来触发。`false` 不会解除。状态发布在 `/racecar_driver/emergency_stop_active`，保留最近状态供新订阅者读取。

锁定记录保存在 `~/.local/state/racecar/emergency_stop`，重启驱动仍保持停车。用解除服务清除，不手动删除文件来绕过状态检查。

## S 弯任务状态

自动试验入口已准备为：

```bash
bash ~/racecar-tests/s-curve-test/run_s_curve.sh
```

因为反向制动尚未标定启用，这条命令目前会在启动节点之前退出并说明原因，不会发车。待刹车标定完成后，该入口将启动现有导航、固定参考路径、检查路径区域、记录轨迹并请求 FollowPath；中断、定位失效、路径偏差超限时会触发急停、取消目标并关闭它自己启动的进程。

本次没有进行实车反向 PWM 测试，也没有进行 S 弯试跑。软件不能仅凭 PWM 指令确认车轮已经停止；实际刹停距离、是否转入倒车及合适的脉冲参数仍需实测。

## 验证范围

验证使用独立 ROS_DOMAIN_ID=197、仅 localhost、操作系统创建的 `/dev/pts/` 虚拟串口和临时锁定文件；不访问 `/dev/car`。覆盖两个驱动入口、反向制动禁用、有限脉冲、重复急停、键盘与导航指令抑制、解除条件、重启锁定、零指令与超时制动。

测试中出现的反向 PWM 和时间仅是软件测试输入，不能作为实车调参值。代码位于 `racecar_driver_node.cpp`；`racecar_driver_node_one.cpp` 复用同一实现。
